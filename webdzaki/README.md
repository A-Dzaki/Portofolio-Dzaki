# Web Portofolio Ahmad Dzaki

Website portofolio pribadi yang dibuat untuk menampilkan informasi diri, kemampuan, proyek, serta kontak yang dapat digunakan sebagai media pengenalan diri secara online. Website ini dikembangkan sebagai salah satu bentuk dokumentasi pembelajaran dan pengembangan skill di bidang web development.

## Tentang Website

Web portofolio ini berisi beberapa bagian utama, seperti:

- Profil singkat atau tentang saya
- Informasi skill dan kemampuan dasar
- Daftar project yang pernah dibuat
- Kontak yang dapat dihubungi
- Link menuju media sosial atau platform pendukung seperti GitHub, Instagram, dan email

Website ini dibuat dengan tampilan sederhana, responsif, dan mudah diakses melalui berbagai ukuran layar, baik desktop maupun mobile.

## Tech Stack

Website ini dibangun menggunakan beberapa teknologi berikut:

- **Laravel** sebagai framework utama untuk struktur project
- **Tailwind CSS** untuk styling dan layout tampilan
- **HTML** untuk struktur halaman
- **CSS** untuk penyesuaian tampilan tambahan
- **JavaScript** untuk interaksi sederhana pada website

## Fitur Website

Beberapa fitur yang terdapat pada website portofolio ini antara lain:

- Tampilan landing page portofolio
- Section tentang saya
- Section skill atau kemampuan
- Section project
- Section contact
- Link email yang mengarah langsung ke Gmail
- Tampilan responsive untuk desktop dan mobile
- Desain modern menggunakan Tailwind CSS

## Tujuan Pembuatan

Website ini dibuat sebagai media portofolio pribadi untuk memperkenalkan diri, menampilkan kemampuan dasar dalam pengembangan website, serta menjadi sarana dokumentasi project yang pernah dikerjakan. Selain itu, website ini juga dapat digunakan sebagai pendukung dalam mencari pengalaman magang atau peluang pengembangan diri di bidang teknologi.
